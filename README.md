# CoSkin

**Codex를 나만의 공간으로.**

움직이는 배경, 테마에 맞춘 아이콘과 행 장식, 편안하게 읽히는 채팅 화면. 테마를 골라 실제 Codex에서 미리 보고, 앱 전체·프로젝트·채팅별로 적용하세요.

## 시작하기

1. [최신 릴리스](https://github.com/GNh0/CoSkin/releases/latest)에서 ZIP을 내려받아 압축을 풉니다.
2. **CoSkin.Loader.exe**를 실행하고 설치 옵션을 선택합니다.
3. Codex와 CoSkin을 실행하고, 왼쪽 아이콘 바에서 **CoSkin**을 엽니다.
4. 테마를 가져오거나 만든 뒤 **미리보기 → 적용**을 누릅니다.

CoSkin을 먼저 켜면 트레이에서 Codex를 기다립니다. 바탕화면의 **CoSkin**으로 독립 실행하거나 시작 메뉴의 **Codex + CoSkin**으로 함께 실행할 수 있습니다. 별도 개발 도구 설치는 필요 없습니다.

**Windows x64**에서 Codex와 CoSkin을 같은 Windows 권한으로 실행하세요. 연결 시 원본 서명과 실제 연결 기능을 확인합니다. 이 문서의 기능과 화면은 **CoSkin 0.1.18 기반의 현재 main 소스**를 기준으로 합니다. 검증 환경과 연결 방식은 [지원 환경](docs/support-matrix.md)에 정리되어 있습니다.

## 테마 고르고 정리하기

카드의 **미리보기**는 실제 Codex 화면에서 테마를 보여 줍니다. **적용**으로 원하는 범위에 반영하고, 미리보기를 취소하면 이전 테마로 돌아갑니다. 상세에서는 정보 수정·편집·복제·내보내기·배경 추출을 할 수 있습니다.

| 테마 목록 | 상세·미리보기 |
| :---: | :---: |
| ![현재 테마 목록](docs/media/current/theme-library.png) | ![현재 테마 상세](docs/media/current/theme-detail.png) |

폴더를 **더블 클릭 또는 Enter**로 열고, 경로·뒤로·앞으로·상위 이동으로 탐색하세요. **폴더 보기/트리 보기**와 **미리보기 카드/한 줄 목록**을 각각 전환할 수 있습니다. 한 줄 목록은 미디어 미리보기를 불러오지 않습니다.

검색·태그·즐겨찾기·정렬, 하위 폴더 포함 검색, 다중 선택 이동을 지원합니다. 테마를 폴더로 드래그하면 분류만 이동하며 파일은 옮기지 않습니다. 페이지당 **24/48/96개**와 직접 페이지 이동을 제공하고 상세에서 돌아와도 목록 위치가 유지됩니다. [목록 관리 안내](docs/theme-library.md)

## 화면 편집과 채팅 가독성

**편집**을 누르고 꾸미려는 영역을 **우클릭**하세요. 전체 배경·본문·입력창·버튼·프로젝트·채팅 행의 이미지, 효과, 글자 스타일을 조절할 수 있습니다. 같은 종류 전체를 편집하거나 **개별 지정**으로 하나만 바꿀 수 있습니다.

밝은 배경에서는 **영상 투명도**를 낮추거나 **본문 배경의 불투명도**를 높여 보세요. 상세의 **글자색 자동 맞춤**은 대비를 우선합니다. 직접 지정 모드에서는 글자색·설치된 글꼴·굵기를 선택할 수 있습니다.

**저장**은 테마 변경을 보관하고, **적용**은 선택한 범위에 반영합니다. 복제본은 원본의 폴더·태그·즐겨찾기를 이어받습니다. AI에게 제작을 맡길 때는 [테마 요청문](docs/theme-request-template.md)과 [파일 사양](docs/theme-package-spec.md)을 함께 전달하세요.

## 움직이는 배경과 배경만 보기

MP4·WebM은 음소거로 반복 재생합니다. 편집에서 **0.1~4배속**, 위치, **화면 채우기/전체 보이기**, 투명도를 조절하세요. 최소화했다 복원하면 재생 위치를 이어갑니다. 영상은 파일당 **512MiB·10분**까지 지원하며 실제 해상도·길이·디코딩을 검사합니다.

제목 표시줄의 **배경만 보기** 또는 **Alt+Shift+B**로 작업 화면을 숨기고 배경을 감상할 수 있습니다. 내장 브라우저까지 숨기는 보완은 **v0.1.18 이후의 main**에 포함됩니다. **화면 복구**, 같은 단축키 또는 **Esc**로 돌아오세요.

GIF나 효과가 움직이지 않으면 테마의 움직임 설정과 Windows의 **움직임 줄이기**를 확인하세요. 큰 GIF는 메모리와 스크롤 성능에 영향을 줄 수 있어 긴 영상에는 MP4·WebM을 권장합니다.

## 배경 저장과 다운로드 관리

상세의 **배경 추출 → 원본 화질 그대로 받기**는 등록된 배경을 재압축 없이 저장합니다. JPG·PNG·MP4·WebM·GIF 변환, **720p·1080p·원본 해상도·직접 입력**도 지원합니다.

다운로드 목록에 작업을 추가하고 **동시 실행 수 1~4개**를 정하세요. 같은 배경과 같은 설정은 중복 추가하지 않으며, CoSkin이 실행 중이면 추출 창을 닫아도 작업이 이어집니다. [배경 저장과 다운로드 관리](docs/background-downloads.md)

## 실행·저장소 설정

트레이에서 테마를 바꾸거나 **CoSkin 설정**을 여세요.

- **연결 창/영상 재생 창 제한**: 기본 5개/2개. 연결 수는 1~10개로, 재생 수는 연결 수 이내로 설정합니다. 활성·최근 사용 창을 우선하며 최소화된 창은 재생을 멈춥니다.
- **시작 인사말 숨기기**: 새 대화의 시작 인사말을 숨기며 입력창은 그대로 둡니다.
- **테마 전체 보관 폴더**: 모든 테마 이미지·영상의 공통 경로와 사용 용량을 확인합니다. 폴더를 바꾸면 파일을 복사하고 SHA256을 검증하며 원래 파일은 보존합니다.
- **Windows 로그인 시 시작 / Codex 종료 시 함께 종료**: 로그인 때 대기하거나 마지막 연결 Codex의 종료에 맞춰 종료합니다.
- **자동 업데이트 / 수동 확인**: GitHub의 새 안정 버전을 확인하고 설치합니다.

같은 미디어는 SHA256 주소로 중복 저장하지 않습니다. 테마 목록·리비전·설정은 기존 CoSkin 저장소에 유지됩니다. 화면이 제대로 그려지지 않으면 트레이의 **테마 새로고침**을 사용하세요.
