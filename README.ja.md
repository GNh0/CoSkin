# CoSkin

**Codexを自分だけの空間に。**

動く背景、テーマに合うアイコンとサイドバー、読みやすい会話画面。Codexでプレビューして、アプリ全体・プロジェクト・チャットごとに適用できます。

## はじめに

1. [最新リリース](https://github.com/GNh0/CoSkin/releases/latest)のZIPを展開します。
2. **CoSkin.Loader.exe**を実行し、インストールオプションを選びます。
3. CodexとCoSkinを起動し、左側のアイコンバーから**CoSkin**を開きます。
4. テーマを読み込むか作成し、**プレビュー → 適用**を選びます。

CoSkinを先に起動するとトレイでCodexを待機します。デスクトップの**CoSkin**で単独起動するか、スタートメニューの**Codex + CoSkin**で両方を起動できます。開発ツールは不要です。

**Windows x64**で同じWindows権限を使用してください。原本の署名と実際の接続機能を確認します。本書の機能と画面は**CoSkin 0.1.18を基にした現在のmainソース**が基準です。[対応環境](docs/support-matrix.md)もご確認ください。

## 選択と整理

**プレビュー**は実際のCodexに表示し、**適用**で選んだ範囲に反映します。キャンセルすると元のテーマに戻ります。詳細では情報編集・複製・書き出し・背景抽出ができます。

| ライブラリ | 詳細 |
| :---: | :---: |
| ![現在の一覧](docs/media/current/theme-library.png) | ![現在の詳細](docs/media/current/theme-detail.png) |

フォルダーは**ダブルクリックまたはEnter**で開きます。パス・戻る・進む・上へ移動に対応します。フォルダー/ツリーとカード/一行表示は別々に切り替えられ、一行表示はメディアを読み込みません。

検索・タグ・お気に入り・並べ替え・下位フォルダー検索・複数選択に対応します。ドラッグは分類だけを変更します。**24/48/96件**表示とページ直接移動ができ、詳細から戻っても一覧位置を保持します。[一覧ガイド](docs/theme-library.md)

## 編集と読みやすさ

**編集**を選び、対象を**右クリック**します。背景・本文・入力欄・ボタン・プロジェクト・チャット行の画像、効果、文字を変更できます。同じ種類全体または**個別指定**を選べます。

明るい背景では**動画の不透明度を下げる**か**本文背景の不透明度を上げる**と読みやすくなります。自動文字色はコントラストを優先し、手動では色・インストール済みフォント・太さを指定できます。

## 動画背景と背景のみ表示

MP4・WebMは無音ループ再生します。**0.1～4倍速**、位置、**画面を埋める/画像全体を表示**、不透明度を調整できます。最小化から戻ると再生を再開します。動画は1ファイル**512MiB・10分**までで、解像度・長さ・デコードを検証します。

タイトルバーの**背景のみ表示**または**Alt+Shift+B**で作業画面を隠します。内蔵ブラウザーも隠す修正は**v0.1.18以降のmain**に含まれます。復元ボタン・同じショートカット・**Esc**で戻れます。

動かないGIFや効果はテーマとWindowsの**動きを減らす**設定を確認してください。大きいGIFはメモリーとスクロールに影響するため、長いアニメーションにはMP4・WebMを推奨します。

## 背景保存とダウンロード管理

**背景抽出 → 原本の品質で保存**は再圧縮せず保存します。JPG・PNG・MP4・WebM・GIF変換と**720p・1080p・元の解像度・任意サイズ**に対応します。

キューと**同時実行1～4件**を使用でき、同じ背景と設定は重複追加されません。CoSkin起動中は抽出画面を閉じても処理が続きます。[保存ガイド](docs/background-downloads.md)

## 実行・保存先の設定

トレイからテーマを切り替えるか**CoSkin設定**を開きます。

- **接続/動画再生数**：初期値5/2。接続は1～10、再生は接続数以内。アクティブ・最近使用した画面を優先し、最小化中は停止します。
- **開始時の挨拶を隠す**：新規チャットの挨拶を隠し、入力欄は残します。
- **共通メディア保存先**：パスと容量を表示。変更時はコピーとSHA256検証を行い、元のファイルを保管します。
- **Windowsログイン時に起動 / Codexと一緒に終了**：待機起動と最後の接続Codexに合わせた終了。
- **自動更新 / 手動確認**：GitHubの安定版を確認・インストールします。

メディアはSHA256で重複保存を避けます。一覧・リビジョン・設定は従来の保存先に残ります。描画に問題がある場合はトレイの**テーマを再読み込み**を使ってください。
