# 독립 실행과 원본 Codex 연결

CoSkin 0.1.0은 트레이를 먼저 준비하고, 실행 순서와 관계없이 지원 Codex를 찾는다. Codex가 없으면 대기하며 CoSkin 실행만으로 Codex를 강제 실행하지 않는다. --with-codex 전용 바로가기는 사용자가 선택한 함께 실행 설정을 따른다.

## 연결 흐름

1. Windows 설치·실행 파일 경로, OpenAI 서명, 패키지·내부 버전과 ASAR 해시를 확인한다.
2. 정확히 검증한 패키지의 chrome.dll 해시와 네이티브 ABI를 확인한다. 대상 HWND의 PID와 UI 스레드를 확인한다.
3. hash를 확인한 내장 DLL을 현재 사용자 CoSkin 저장소에 해제하고, 대상 UI 스레드의 제한된 메시지 훅에서 연결 준비를 요청한다. 원본 실행 파일·ASAR를 패치하지 않는다.
4. 요청의 PID·소유 호스트·30초 유효 시간·nonce를 확인한다. Node inspector를 127.0.0.1 임시 포트에 열고 응답과 실제 포트 소유 PID를 재확인한다.
5. Node 쪽 브리지는 확인한 주 앱/분리 창의 webContents만 선택한다. 렌더러 중계는 Runtime.enable/addBinding/evaluate/removeBinding, Page.bringToFront로 제한한다. 웹사이트 webview·로그인·아바타 창을 임의로 선택하지 않는다.
6. 지원 렌더러 버전·문서를 다시 확인한 뒤 CoSkin API를 주입하고 저장된 적용 상태를 복원한다. 트레이 명령은 탐색 바가 있는 주 창을 선택한다.

일반 실행 연결의 검증 대상은 **Windows 패키지 26.924.2738.0 / 내부 앱 26.924.22138**이다. 패키지의 ASAR SHA-256은 89FBA67324FFB8DD54CCF13B6F097172E697549EEB1F26396F86F972C10C5B0C, chrome.dll은 B6F5C2323C642C3AD3DFDC3501AA94482970F88B4C12DB0875CE593AECE75C16이다. 향후 Codex 업데이트는 새로운 호환성 검증이 필요하다. 다른 버전을 우회해 연결하지 않는다.

두 앱의 Windows 권한 수준이 같아야 한다. 관리자 Codex와 일반 CoSkin 사이에 자동 권한 상승을 시도하지 않는다. 기존 패키지의 관리 연결과 명시적 --port는 별도 검증 경로를 유지한다.

## 대기·재연결·종료

유휴 감지는 창 생성/종료 및 연결 기록 변경 이벤트를 사용한다. 준비 지연에는 최대 6회 제한된 재검사를 하고, 소진되면 이벤트를 기다린다. 네이티브 준비는 PID·시작 시각별 최대 3회이며 명시적인 다시 연결이 예산을 초기화한다. 잘못된 신원과 지원하지 않는 빌드는 연결하지 않는다.

연결 중에는 약 2초 간격의 건강 확인을 사용한다. 해당 Node inspector가 WebSocket 자동 keepalive 프레임을 거절해 30초마다 끊기던 문제를 수정했고, 응용 요청과 제한된 명령 타임아웃으로 상태를 확인한다.

CoSkin 직접 종료는 Codex를 종료하지 않는다. 정상 해제는 자기 소유 endpoint에 closing 표시를 남기고 렌더러 중계를 해제한 뒤, 소유자가 바뀌지 않았을 때만 inspector를 닫는다. 재연결한 새 호스트의 통로를 이전 호스트가 닫지 않게 한다.

호스트가 강제 종료되면 90초 임대 만료로 브리지가 소유한 렌더러 debugger/listener를 해제한다. **Node inspector 포트가 강제 종료 즉시 닫힌다고 보장하지 않는다.** 다음 CoSkin 연결 또는 Codex 종료까지 살아 있을 수 있다. 같은 PC의 다른 프로그램이 접근 가능한 로컬 진단 통로라는 점을 숨기지 않는다.

마지막 연결 대상이 종료되면 함께 종료 옵션에 따라 CoSkin도 종료하거나 다시 트레이에서 대기한다. 로그인 시작은 독립적인 선택이며, 새 저장소의 기본값은 꺼짐이다.

## 설치와 진단

설치된 기본 저장소와 실행 파일 소유권을 확인한 뒤 HKCU의 CoSkin.Resident 시작 항목만 관리한다. 검수용 --store에서 전역 등록 변경은 거절한다. 버전 교체는 설치 기록·바탕화면·시작 메뉴·로그인 경로를 함께 갱신하며 실패 시 이전 등록 상태를 복구한다. 다른 앱의 등록이나 동명 다른 바로가기를 덮지 않는다.

바탕화면 **CoSkin**은 독립 --resident, 시작 메뉴 **Codex + CoSkin**은 --with-codex다. 테마는 트레이 하위 메뉴로 묶고 언어는 연결된 Codex를 따른다. 메뉴 표시 시 임시 소유 창을 앞으로 가져와 메뉴가 아이콘 패널 뒤에 남지 않도록 처리한다. 실제 Explorer의 모든 포커스 동작은 별도 검수 범위다.

로컬 진단 파일은 %LOCALAPPDATA%\CoSkin\diagnostics\resident.jsonl이다. 시각·호스트 PID·버전·단계·오류 종류/코드만 기록하며, 대화·이미지 bytes·예외 원문은 쓰지 않는다. 두 개의 256KiB 파일로 회전하고 서버로 업로드하지 않는다.

실제 설치본의 일반 자동 연결·두 창·원본 프로세스 유지·업데이트 결과와 제한은 [지원표](support-matrix.md), 서명 배포는 [업데이트 문서](updates.md)를 기준으로 한다.
