# CoSkin 0.1.14

The current Dot conversation has opaque messaging surfaces beneath a deeper chain of full-area wrappers than ordinary task pages. CoSkin now follows a bounded, single full-area shell branch through up to sixteen levels. Newly mounted plain structural wrappers also trigger discovery. Message bubbles, editors, the right and bottom panels, and cloud computer previews keep their native paint. This uses shell geometry and content boundaries rather than a Dot route name, so equivalent layouts on new pages can be detected without making every panel transparent.

Automated theme imports can use `showLibrary: false` to commit a package and notify connected library views without opening the theme manager or navigating the current page. Existing interactive imports still open the library by default. The option accepts a boolean only on import requests.

Regression tests cover the observed deep Dot structure, preserved message and computer-panel backgrounds, and late structural discovery without reacting to streamed message content. They do not establish compatibility with every Dot state or unknown future page, and this release does not extend the previously measured multi-window playback load.
