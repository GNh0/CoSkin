# 배경 저장과 다운로드 관리

테마 상세에서 **배경 추출**을 열고 저장할 위치를 선택하세요. 현재 프로필에 등록된 배경을 저장하며, 프로필의 개별 수정 배경이 있으면 그 파일을 사용합니다.

**원본 화질 그대로 받기**는 원본 파일을 해상도 변경이나 재압축 없이 복사합니다. 영상은 전체 길이를 보존하고, 원본 파일 형식과 투명도도 그대로 유지합니다. 압축 화질의 **고화질**과는 별개의 선택입니다.

형식이나 크기를 바꾸려면 저장 형식과 해상도를 고른 후 **저장 위치 선택하고 추출**을 누르세요.

| 설정             | 선택                                       |
| ---------------- | ------------------------------------------ |
| 이미지 배경      | 원본·JPG·PNG                               |
| 영상·움짤 배경   | 원본·JPG·PNG·MP4·WebM·GIF                  |
| 해상도           | 원본·720p·1080p·직접 입력                  |
| 압축 화질        | JPG·MP4·WebM에서 고화질·표준·작은 용량     |
| 이미지 추출 시점 | 영상·움짤의 JPG·PNG 저장 시 초 단위로 지정 |

720p·1080p는 세로 높이를 기준으로 원본 비율을 유지합니다. 직접 입력에서 **화면 비율 유지**를 선택하면 지정한 가로·세로 범위 안에 맞춥니다. JPG·MP4는 투명한 부분을 검정으로 합성하며, PNG·WebM은 투명도를 보존합니다.

변환에는 FFmpeg가 필요합니다. 자동으로 찾지 못하면 **변환기 선택**에서 `ffmpeg.exe`를 선택하세요. 원본 저장에는 변환기가 필요하지 않습니다.

목록 또는 상세의 **다운로드 목록**에서 대기·진행·완료·실패 상태를 관리할 수 있습니다. 목록에는 계속 추가할 수 있고 **동시 다운로드**는 기본 2개, 1~4개로 설정할 수 있습니다. 실행 수를 낮추면 진행 중인 작업은 마치고 새 작업부터 제한을 적용합니다.

같은 배경에 같은 형식·해상도·화질·이미지 추출 시점을 요청하면 기존 항목을 보여줍니다. 원본 저장은 사용하지 않는 변환 설정과 관계없이 같은 작업으로 판단합니다. 실패·취소 항목의 **다시 받기**는 기존 항목과 저장 위치를 사용합니다.

**종료된 기록 지우기**는 완료·실패·취소 기록만 지웁니다. 저장한 파일은 유지하며, 기록을 지운 뒤에는 같은 설정으로 새 다운로드를 추가할 수 있습니다.

추출 창을 닫거나 다른 화면으로 이동해도 CoSkin이 실행 중이면 작업은 계속됩니다. CoSkin을 종료하면 작업이 취소되며 다운로드 기록은 다음 실행에 복원되지 않습니다. 동시 다운로드 설정과 변환기 선택은 다음 실행에도 유지됩니다.
