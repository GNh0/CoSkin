# CoSkin 0.1.18

테마 상세 화면에서 편집을 시작하면 기존 전체 배경을 바로 바꿀 수 있습니다. 이전 편집 대상이 본문에 남아 있어 새 영상을 올릴 때 전체 배경 위에 본문 영상이 겹치는 문제를 수정했습니다. 본문에만 배경을 둔 기존 테마는 본문 배경에서 편집을 시작합니다.

편집 대상 목록에서 전체 배경, 본문, 프로젝트·채팅 행, 버튼 등 바꿀 영역을 직접 선택할 수 있습니다. 영역을 옮기면 이전 영역의 개별 항목·표시 조건·레이어 선택을 초기화합니다. 기존 우클릭 편집도 유지합니다.

복제본에 폴더·태그·즐겨찾기도 함께 저장합니다. 배경·아이콘·장식·색상·효과·프로필·개별 설정과 자산 참조를 복제하고, 원본 리비전과 적용 중인 테마는 보존합니다. 복제는 자동 적용하지 않습니다.

이미 본문에 저장된 배경은 그대로 남습니다. 편집 대상에서 본문 배경의 이미지를 숨기고, 전체 배경에 새 파일을 지정하면 됩니다. 원래 본문에만 배경을 두려는 테마를 보호하기 위해 저장된 설정을 일괄 변경하지 않습니다.
