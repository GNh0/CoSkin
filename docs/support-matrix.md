# CoSkin 0.1.0-beta.1 검증 범위

2026-09-26. 첫 Windows x64 테스트 배포를 위한 독립 검수 기록의 공개 요약이다. 개인 대화, 사용자 자산과 원시 로그는 포함하지 않는다.

| 영역 | 확인한 범위 | 제한 |
| --- | --- | --- |
| 실행 파일 | self-contained Windows x64 실행 파일로 검수용 Codex에 연결, 기존 테마와 자산 복원 | 일반 Windows 새 사용자 설치와 모든 실행 경로를 보장하지 않음 |
| 지원 Codex | Windows 패키지 26.924.1866.0, 내부 앱 26.924.20706 | 다른 버전은 호환성 검수 전 연결 중지 |

| 자동 검사 | Node 36개, .NET 호스트 113개, ESLint·TypeScript 검사 통과 | 테스트 중 설치 레지스트리·호스트 교체는 대체 플랫폼을 사용; 실사용 성공의 대용이 아님 |

설치 UI는 동일 소스·Windows 공통 컨트롤 manifest를 사용하는 별도 실행형 검수 프로그램에서 4개 언어의 카드·토글·버튼을 렌더링해 확인했다. 설치를 실행하는 검사는 아니며, 실제 Windows 조작 도구의 캡처·클릭 오류 때문에 키보드 전체 동선 검증을 완료했다고 주장하지 않는다. 디자인 변경 전 후보는 실행 파일·렌더러·고지 3개가 실제 사용자 설치 기록과 해시까지 일치함을 확인했다. 최종 배포 ZIP은 별도로 CRC와 3개 파일의 원본 일치·SHA-256을 검사했다.

## 실행 연결의 현재 한계

검증된 연결은 루프백 디버깅 통로가 열린 Codex를 대상으로 한다. 일반 바로가기로 실행한 원본 Codex를 발견하는 것만으로 이 통로가 생기지는 않는다. 첫 후보의 실행 방식은 전용 `Codex + CoSkin` 바로가기와 별도 관리 복사본을 사용한다. 원본 설치 파일·ASAR·기존 바로가기와 실행 중인 원본 프로세스를 바꾸거나 강제 종료하지 않는다.

요청된 후속 구조는 **CoSkin 수동 실행 또는 Windows 로그인 시 시작 → 트레이 대기 → 이미 실행 중이거나 나중에 실행한 Codex에 연결 → Codex 종료 후 다시 대기**다. 일반 실행 원본에 대한 연결 경로는 아직 확보하지 못했다. 따라서 이 구조를 이미 지원하는 것으로 안내하지 않는다.

## 성능 상태

왼쪽 목록 위에 포인터를 둔 실제 휠 스크롤 검사에서, 정지 배경을 사용한 최신 후보는 이전의 큰 추가 지연을 재현하지 않았다. 이 결과를 GIF 배경의 스크롤 성능으로 일반화하지 않는다. GIF를 적용한 실제 채팅에서는 사용자가 끊김을 보고했으며, 첫 배포 이후의 우선 개선 항목이다. 기본 제공 테마는 정지 배경을 사용한다.

GIF 예제 화면은 실제 재생을 확인하기 위한 자료이며 프레임률·CPU·메모리 벤치마크가 아니다. 최대 크기 패키지와 여러 고해상도 GIF의 자원 사용 예산은 추가 검증이 필요하다.
