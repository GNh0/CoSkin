## 한국어

CoSkin 0.1.3은 배경 장식이 Codex 창의 실제 모서리와 맞지 않아 오른쪽 아래에 검은 네모가 남던 문제를 수정합니다. GIF와 MP4 배경은 기본 상단 제어 영역 아래에서 표시하며, 왼쪽 목록의 반투명 배경 흐림도 정상 적용됩니다. 보조 창 초기화가 늦어져도 주 창 연결을 유지하고 해당 보조 창만 다시 시도합니다. 목록 스크롤 시 불필요한 반복 탐색을 줄였습니다.

기존 테마, 개인 영상, 라이브러리와 적용 상태는 업데이트에 포함되거나 교체되지 않습니다. 원본 Codex 설치 파일은 수정하지 않습니다. 지원 범위와 검증 결과는 [지원·검증 범위](https://github.com/GNh0/CoSkin/blob/v0.1.3/docs/support-matrix.md)를 참조하세요.

## English

CoSkin 0.1.3 fixes the black square left at the bottom-right corner when a background decoration used a radius that differed from the Codex window. GIF and MP4 backgrounds now start below the native top controls, and the translucent left sidebar blur renders correctly. A slow secondary window is retried independently without dropping the primary window. Sidebar scrolling avoids repeated ancestor lookups.

The update does not include or replace personal themes, videos, library data, or the current applied theme. It does not modify the original Codex installation. See the [support and validation scope](https://github.com/GNh0/CoSkin/blob/v0.1.3/docs/support-matrix.md).

## 日本語

CoSkin 0.1.3 では、背景の角丸が Codex ウィンドウと一致せず、右下に黒い四角が残る問題を修正しました。GIF と MP4 の背景は標準の上部操作領域の下から表示され、左サイドバーの半透明ぼかしも正しく反映されます。補助ウィンドウの初期化が遅れてもメインウィンドウとの接続を維持し、補助ウィンドウだけを再試行します。サイドバーのスクロール時の重複探索も削減しました。

更新に個人のテーマ・動画・ライブラリや現在の適用状態は含まれず、置き換えられません。元の Codex インストールは変更しません。[対応・検証範囲](https://github.com/GNh0/CoSkin/blob/v0.1.3/docs/support-matrix.md)も参照してください。

## 简体中文

CoSkin 0.1.3 修复了背景圆角与 Codex 窗口不一致、右下角残留黑色方块的问题。GIF 和 MP4 背景现在从原生顶部控件下方开始显示，左侧栏的半透明模糊也能正确呈现。副窗口初始化较慢时，主窗口连接会保持，只重试该副窗口。侧栏滚动时也减少了重复查找。

更新不会包含或替换个人主题、视频、主题库及当前应用状态，也不会修改原版 Codex 安装文件。详见[支持与验证范围](https://github.com/GNh0/CoSkin/blob/v0.1.3/docs/support-matrix.md)。
