## 한국어

CoSkin 0.1.4에는 AI에게 테마 제작을 요청할 때 쓸 수 있는 **테마 요청문** 기능을 추가했습니다. CoSkin과 `.coskin` 파일의 구조를 설명하는 요청문을 앱에서 열어 편집하고 복사할 수 있습니다. GitHub에는 현재 소스의 검사 규칙에 맞춘 [테마 파일 사양](https://github.com/GNh0/CoSkin/blob/v0.1.4/docs/theme-package-spec.md), 기본 예시와 패키징 도구도 공개했습니다.

기존 테마와 개인 미디어는 릴리스 ZIP에 포함되지 않습니다. 기존 Codex 설치 파일은 수정하지 않습니다. 앱에서 새 기능을 보려면 0.1.4로 업데이트하세요.

## English

CoSkin 0.1.4 adds an editable, copyable **theme request** prompt in the app. It explains CoSkin and the `.coskin` package to an AI theme creator. GitHub now includes the [theme package specification](https://github.com/GNh0/CoSkin/blob/v0.1.4/docs/theme-package-spec.md), a starter example, and a packaging helper aligned with the current source validators.

Existing themes and personal media are not included in the release ZIP. The original Codex installation is not modified. Update to 0.1.4 to use the new in-app action.

## 日本語

CoSkin 0.1.4 では、AI にテーマ制作を依頼するための編集・コピー可能な **テーマ依頼文** をアプリに追加しました。CoSkin と `.coskin` パッケージの構造を説明します。GitHub には現行ソースの検証規則に沿った [テーマパッケージ仕様](https://github.com/GNh0/CoSkin/blob/v0.1.4/docs/theme-package-spec.md)、基本サンプル、パッケージ作成ツールも公開しました。

既存のテーマや個人メディアはリリース ZIP に含まれません。元の Codex インストールは変更しません。アプリ内の新機能を使うには 0.1.4 に更新してください。

## 简体中文

现有主题和个人媒体不会包含在发布 ZIP 中。原版 Codex 安装不会被修改。更新到 0.1.4 后即可使用应用内新功能。
