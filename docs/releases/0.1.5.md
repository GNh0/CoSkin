## 한국어

CoSkin 0.1.5는 간헐적으로 트레이 메뉴가 화면에 남는 문제를 줄입니다. 메뉴 소유 창이 전경으로 활성화된 경우에만 메뉴를 열고, 메뉴가 열린 동안 중복 호출을 무시하며, 다른 창으로 포커스가 이동하면 메뉴를 닫습니다. 설치된 빌드에서 트레이 메뉴 열기·바깥 클릭 10회가 모두 정상적으로 닫혔습니다. 간헐적인 원래 현상을 동일 조건으로 재현한 것은 아니므로 완전한 해결 여부는 계속 관찰합니다.

Codex가 숨겨둔 채팅 탭 대신 실제로 보이는 채팅 영역에 테마의 명암 레이어를 적용합니다. 레이어가 사라졌을 때 트레이의 **테마 새로고침**으로 다시 표시할 수 있습니다. 기존 테마와 개인 미디어는 배포 ZIP에 포함되지 않으며 원본 Codex 설치 파일을 수정하지 않습니다.

## English

CoSkin 0.1.5 reduces cases where the tray menu remains on screen. It opens the menu only after activating its owner, ignores duplicate callbacks while open, and dismisses it when focus moves to another window. Ten real open/outside-click cycles closed normally on the installed build. The original intermittent case was not reproduced under identical conditions, so continued observation is needed.

Theme dimming now attaches to visible chat surfaces instead of hidden tabs. **Refresh theme** in the tray restores the decoration if it disappears. Existing themes and personal media are excluded from the release ZIP; the original Codex installation is unchanged.

## 日本語

CoSkin 0.1.5 は、トレイメニューが画面に残ることがある問題を軽減します。所有ウィンドウを前面にできた場合のみメニューを開き、表示中の重複コールバックを無視し、別のウィンドウへフォーカスが移ると閉じます。インストール済みビルドで開く・外側をクリックする操作を10回確認し、すべて閉じました。元の断続的な現象を同じ条件で再現できていないため、引き続き観察が必要です。

テーマの暗さ調整を非表示タブではなく表示中のチャット領域に適用します。消えた場合はトレイの **テーマを再表示** で復元できます。既存テーマと個人メディアは配布 ZIP に含まず、元の Codex インストールは変更しません。

## 简体中文

CoSkin 0.1.5 减少托盘菜单偶尔停留在屏幕上的情况。只有成功激活菜单所属窗口时才显示菜单；显示期间忽略重复回调，焦点转到其他窗口时关闭菜单。已安装版本的10次打开及点击菜单外侧测试均正常关闭。原先的间歇性问题尚未在相同条件下重现，因此仍需继续观察。

主题调暗层现在附着到可见的聊天区域，而非隐藏标签页。调暗层消失时，可使用托盘中的 **刷新主题** 恢复。发布 ZIP 不包含现有主题或个人媒体，也不会修改原版 Codex 安装。
