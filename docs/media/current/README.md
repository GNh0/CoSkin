## 캡처 방법

라이브러리·상세·편집·설정 화면은 저장소의 실제 UI 컴포넌트와 스타일을 별도의 읽기 전용 캡처 환경에서 실행했습니다. 사용자 앱을 조작하거나 가짜 UI로 다시 그린 화면이 아닙니다. 현재 라이브러리와 등록된 테마 문서를 읽었으며, 네이티브 쓰기 작업은 캡처 환경에서 차단했습니다.

테마 예시는 실제 CoSkin Decoration·미디어 재생·글자 스타일 렌더러를 샘플 작업 화면에 적용했습니다. 실제 사용자 Codex 창의 스크린샷이 아니며, 프로젝트·채팅 이름과 본문은 예시입니다. 영상 재생, 정지 이미지 프로필, 호버 효과를 확인하고 프레임을 저장했습니다.

요청에 따라 니케·브라운더스트2 폴더와 하위 항목을 **캡처용 라이브러리 복사본에서만** 제외했습니다. 원래 라이브러리·파일·설정은 유지되며, 캡처 전후 저장소 해시가 같음을 검증했습니다.

움직이는 WebP는 문서를 가볍게 표시하기 위한 축소본입니다. 테마에서는 원래 MP4를 재생합니다. 문서 영상의 낮은 프레임 수와 축소 해상도는 실제 테마의 재생 품질을 나타내지 않습니다.

## 테마 구성

세 기본 예시는 서로 다른 27개 아이콘과 프로젝트·채팅 행 이미지를 사용합니다. 프로젝트는 윤곽이 있는 카드로, 채팅은 더 작은 아이콘과 줄인 장식으로 구분합니다. 각 테마에는 영상과 정지 이미지 프로필이 있습니다.

현재 사용자가 설정한 비 오는 밤의 영상 불투명도 55%를 캡처에도 반영했습니다. 다른 사용자나 설치에서 같은 값을 강제로 적용하는 설정은 아닙니다.

추가 예시인 푸른 공명은 눈·입·고개·상체가 움직이는 2D 원화 영상에 별도의 공명 아이콘·파형 장식을 사용합니다. 배경은 공개 1080p 영상에서 하단 안내 영역 120px를 제외한 1920×960 편집본입니다.

원본 영상·개인용 테마 패키지와 검증 로그는 Git 저장소에 포함하지 않았습니다. [소재 출처](ASSET-NOTES.md)
