# 에이메스 2D 테마 소재

README 예시는 명조의 에이메스를 사용한 비공식 팬 테마입니다.

| 테마 | 공개 영상 출처 | 사용한 영상 |
| --- | --- | --- |
| 하늘 비눗방울 | [MotionBGS — Aemeath WuWa](https://motionbgs.com/aemeath-wuwa) | 1920×1080, 약 12초 |
| 비 오는 밤 | [MotionBGS — Aemeath Rainy Memories](https://motionbgs.com/aemeath-rainy-memories) | 3840×2160, 약 12초 |
| 속삭이는 별빛 | [Destiny Sullivan — Aemeath Whispering Stars](https://www.youtube.com/watch?v=_sBxWFPAWX8) | 1920×1080, 약 10초 |
| 푸른 공명 | [NikkiWay — Aemeath](https://www.youtube.com/watch?v=NzbvVY1nJXA) | 공개 1920×1080 원본, 약 9초 |

캐릭터와 게임 원작의 권리는 Kuro Games에, 개별 팬아트와 영상의 권리는 각 제작자에게 있습니다. 위 출처는 해당 영상을 제공한 페이지이며, 확인되지 않은 원화가의 이름을 새로 지정하지 않았습니다.

푸른 공명은 공개 2D 원화 영상의 하단 안내 문구 영역 120px를 제외한 개인용 편집본입니다. 1920×960으로 저장했으며 원본 영상은 보존했습니다. 비공개·유료 원본을 사용한 것이 아닙니다.

아이콘의 벡터 디자인, 프로젝트·채팅 행 장식, 색상과 테마 효과는 이 CoSkin 예시용으로 제작했습니다. 세 테마는 각각 펄·비눗방울, 네온·빗줄기, 금빛 별·날개를 사용합니다. 프로젝트와 채팅의 윤곽·장식 강도를 구분했습니다.

README의 PNG·움직이는 WebP는 CoSkin의 실제 렌더러로 캡처한 샘플 화면입니다. WebP는 문서용 축소 예시이고, 테마 배경 자체는 MP4입니다. 원본 전체 영상이나 개인용 .coskin 패키지는 이 디렉터리에 포함하지 않습니다.

이 문서는 소재 출처를 설명하며, 원작과 외부 영상에 새로운 라이선스를 부여하지 않습니다. [캡처 방법](README.md)
