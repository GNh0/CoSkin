# CoSkin 0.1.0-beta.1

첫 Windows x64 테스트 배포입니다. Codex 내부 테마스킨 목록·상세·편집·이미지·효과를 시험하기 위한 비공식 확장이며, 정식 제품 완료를 의미하지 않습니다.

[한국어](../README.md) · [English](../README.en.md) · [日本語](../README.ja.md) · [简体中文](../README.zh-CN.md)

## 설치

`coskin-0.1.0-beta.1-win-x64.zip`을 풀고 파일 3개를 함께 둔 상태에서 `CoSkin.Loader.exe`를 실행합니다. 설치 후 시작 메뉴의 **Codex + CoSkin**을 사용합니다. Node 또는 .NET을 별도로 설치할 필요는 없습니다. 원래 Codex가 켜져 있으면 작업을 저장하고 직접 정상 종료한 뒤 실행합니다.

검수 기준은 Codex Windows 패키지 **26.924.1866.0**, 내부 앱 **26.924.20706**입니다. 원본 설치 파일이나 기존 바로가기를 변경하지 않습니다.

## 포함한 기능

- CoSkin 전용 목록 페이지와 카드·상세, 미리보기·편집·저장·적용.
- PNG/JPEG/GIF, 독립 불투명도와 아이콘, 프로젝트/채팅 행의 전체·개별 설정.
- 상태별 효과와 사용자 정의 선언형 효과, `.coskin` 가져오기·내보내기.
- 시스템 트레이와 실행·종료 설정, 4개 언어 UI와 README.
- 다크 톤의 설치 화면과 옵션 카드·토글·완료 안내.

## 이번 베타의 제한

- **GIF 배경을 사용하는 채팅 스크롤에서 정지·버벅임이 발생할 수 있습니다.** 첫 배포 이후 우선 개선합니다. 기본 테마는 정지 배경입니다.
- **일반 바로가기로 실행한 원본 Codex에 자동 연결하는 기능과 Windows 로그인 시 CoSkin 자동 시작은 아직 지원하지 않습니다.** 현재 연결은 전용 실행 방식입니다. 단독 상주·감지·연결 구조는 후속 검증 대상입니다.
- 자동 업데이트 설정은 있으나 실제 자동 다운로드·교체 배포는 준비되지 않았습니다. 새 버전은 수동으로 설치합니다.
- 새 Windows 사용자 환경의 전체 설치 흐름, 모든 효과 조합, 다중 창·혼합 DPI, 최대 패키지 메모리와 실행 중 제거의 잔여 파일 정리는 추가 검수 대상입니다.

[검증 범위와 한계](support-matrix.md)를 확인하세요. 테스트는 Node 36개, .NET 호스트 113개가 통과했습니다. 일부 호스트 검사는 대체 플랫폼을 사용하며 모든 실제 사용자 동작을 검증했다는 뜻은 아닙니다.
