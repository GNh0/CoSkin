# CoSkin 0.1.13

Background-only view no longer clips the top of the image a second time. The background stays below the native titlebar, while the ordinary app-header clip is temporarily released and restored when the interface returns. The same canvas/video player, source aspect ratio and playback position are retained.

Project Home greeting detection now supports the current native hero with its inline project-selector button. The start-screen hiding option also covers Home task suggestions and their explicitly linked tooltips in the same start screen, including suggestions mounted before the hero. Composer controls, messages, other pages and unrelated tooltips remain outside that scope. Delayed heading text and newly mounted suggestions trigger a bounded refresh; conversation text updates do not trigger full discovery.

The resident command channel gives large theme imports the existing fifteen-minute media validation budget. Previously its fixed thirty-second deadline could close the reply pipe while a valid video package was being checked or stored. Ordinary commands and the initial request read retain their short bounds, and a second launch waiting for an import uses the matching budget.

This release retains the connection/playback limits and media budgets from 0.1.12. It does not establish ten-window simultaneous playback performance or universal compatibility with future Codex layouts.
