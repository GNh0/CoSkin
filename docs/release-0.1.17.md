# CoSkin 0.1.17

등록된 테마 배경을 원본 그대로 저장하거나 JPG·PNG·MP4·WebM·GIF로 변환할 수 있습니다. 원본 화질 저장은 해상도와 파일 바이트를 그대로 보존하며, 변환 시에는 원본 해상도·720p·1080p·직접 입력을 선택할 수 있습니다.

다운로드 목록은 대기 작업을 계속 추가하고 실행 중인 작업만 기본 2개, 최대 4개로 제한합니다. 같은 배경과 설정을 중복 추가하지 않으며, 취소와 같은 항목 재시도, 종료된 기록 정리를 지원합니다. CoSkin이 실행 중이면 추출 창을 닫아도 작업이 계속됩니다.

저장 위치는 Windows 파일 선택 창에서 지정합니다. 완료된 결과만 최종 파일에 반영하며, 실패하거나 취소하면 기존 파일과 등록된 배경을 유지합니다. 변환에는 FFmpeg가 필요하고 원본 저장은 별도 변환기 없이 사용할 수 있습니다.

다운로드 기록은 현재 CoSkin 실행 동안 유지됩니다. 동시 실행 수와 선택한 변환기는 다음 실행에도 유지됩니다.

미리보기는 첫 배경 이미지를 먼저 읽고 영상이 준비되면 교체합니다. 미리보기 취소와 배경만 보기의 응답 처리도 개선했습니다. 채팅 아이콘 배치 중 연결을 끊던 오류를 수정하고, 기본 진행·검토 아이콘을 유지하면서 테마 아이콘을 별도로 표시합니다. 더보기 메뉴의 프로젝트·사이트·지도·GPT·코드 리뷰에도 아이콘 설정을 적용할 수 있습니다.

연결된 여러 창과 Dot 화면에도 같은 테마를 유지합니다. 큰 영상 변환과 렌더 작업이 동시에 실행될 때의 간헐적 미리보기 지연은 별도 확인 중입니다.
